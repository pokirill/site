# Бэклог сайта

## Оплата (разбор кабинета 26.10.2026)

| Ключ | Что | Зачем |
|---|---|---|
| PAY-SUPPORT-EMAIL-1 | Почта поддержки на домене (например, `support@kubysh.com`) вместо `KubyshkaAI@Proton.Me` в подвале кабинета. Почты на домене пока нет, DNS в Cloudflare меняет Кирилл | доверие на платежной странице |
| PAY-PAYBACK-1 | Личные цифры в кабинете: экономия прошлого периода, дата цели, «подписка окупилась в N раз». Нужен эндпоинт бэка со сводкой периода по аккаунту (`account_installations` → данные установки); сумм в аналитику не писать | самый сильный довод платить, на цифрах человека |
| PAY-REFUND-1 | Гарантия возврата в первые 14 дней. Отложено: человек к пейволу уже пользовался Кубышем N дней | снять риск первой оплаты |
