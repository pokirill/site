# SEO и GEO для kubysh.com

Актуально на 18 сентября 2026 года. Цель — приводить из поиска людей, которым нужен
ответ «сколько можно потратить сегодня и хватит ли денег до следующей получки», а затем
измерять переходы в App Store и установки.

## Что можно и нельзя обещать

Нельзя гарантировать позицию №1: выдача зависит от конкурентов, истории домена,
внешних упоминаний, поведения пользователей и персонализации. Можно системно улучшать
индексацию, релевантность, доверие, цитируемость и конверсию.

## Приоритет поисковых интентов

1. **Категория Кубыша:** сколько можно тратить сегодня; сколько можно тратить в день;
   хватит ли денег до зарплаты; бюджет до следующей зарплаты.
2. **Выбор инструмента:** приложение для планирования бюджета; планировщик бюджета;
   приложение для контроля расходов; приложение для личных финансов на iPhone.
3. **Работа с получкой:** как распределить зарплату; бюджет на месяц; обязательные
   платежи; свободный остаток.
4. **Накопления:** как копить деньги; финансовая подушка; калькулятор накоплений;
   финансовые цели.
5. **Конкретные цели:** накопить на отпуск, машину, квартиру, телефон или свадьбу.

Главная страница отвечает за продукт и категорию. Страница `/skolko-mozhno-tratit/`
отвечает за формулу доступной суммы. Страница `/lichnye-finansy/` связывает гайды.
Остальные страницы получают один основной интент каждая. Новая страница создаётся
только при новом интенте, а не ради перестановки тех же слов.

## Реализованная техническая база

- уникальные canonical URL и XML sitemap только с каноническими адресами;
- правдивый `lastmod` без неиспользуемых Google полей `priority` и `changefreq`;
- структурированные сущности Organization, WebSite, SoftwareApplication, Article,
  CollectionPage, AboutPage, BreadcrumbList и FAQPage;
- единые Open Graph и Twitter-превью;
- видимая внутренняя ссылка с главной на хаб материалов;
- открытый доступ OAI-SearchBot и фактическая справка `/llms.txt`;
- IndexNow для быстрой передачи изменённых URL Bing и другим участникам протокола;
- источники и методология на финансовых материалах;
- событие `seo_appstore_click` для переходов в App Store.

## Что даёт рост вне кода

Для SEO и особенно GEO недостаточно собственного сайта. Нужны независимые упоминания,
которые подтверждают, что Кубыш — реальный продукт и отдельная категория. Приоритет:

1. публикации и обзоры с прямой ссылкой на релевантную страницу kubysh.com;
2. страницы автора и продукта на уже существующих внешних площадках;
3. честные сравнения и кейсы, которые можно проверить;
4. ссылки из тематических материалов про бюджет между зарплатами;
5. никаких покупных ссылочных сетей и массовых текстов под ключи.

## Измерение

Нужно подключить и проверить владельца сайта в Google Search Console, Яндекс Вебмастере
и Bing Webmaster Tools, затем отправить `https://kubysh.com/sitemap.xml`.

Раз в неделю фиксировать:

- запрос, страницу, показы, клики, CTR и среднюю позицию;
- долю проиндексированных канонических страниц;
- переходы в App Store по источнику и странице;
- запросы, где показы уже есть, но CTR или позиция слабые;
- упоминания и ссылки на Кубыш во внешних источниках;
- цитирование kubysh.com в ChatGPT, Copilot, Gemini, Perplexity и Яндекс Нейро по
  стабильному набору вопросов.

Решения по заголовкам принимаются после накопления данных, а не по разовой ручной
проверке выдачи. Новые страницы создаются только по запросам с отдельным интентом.

## Следующая содержательная очередь

1. Улучшать страницу `/skolko-mozhno-tratit/`, если она получает показы без кликов.
2. Усилить продуктовую страницу `/prilozhenie-dlya-kontrolya-rashodov/` по данным
   коммерческих запросов.
3. Добавлять реальные примеры и расчёты на страницы с показами, но слабой позицией.
4. Создавать новые материалы только после выгрузки реальных запросов из панелей
   вебмастеров.
